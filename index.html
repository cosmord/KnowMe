06 //06. Philosophy

Principles

Four rules that guide every tool I build.

  • 📴

    Offline by default

    Tools work without a connection. Your data never leaves your device — Irisbytes scans with zero cloud, zero calls home.

  • 👻

    Zero telemetry

    No tracking, no analytics, no data collection. Nothing to hide, nothing to spy on.

  • 🧾

    Audit-friendly

    Readable, auditable code meant to be read, not just run. Security by design, from the first commit.

  • 🌍

    Open source

    Knowledge and code shared openly. Collective security grows when everything is public.

Privacy is a right, not a feature.
